# GamingStore - E-commerce (Primer Desafío Práctico DPS)

Aplicación de comercio electrónico desarrollada con React, TypeScript y Next.js para el curso Diseño y Programación de Software Multiplataforma - UDB.

## Tecnologías

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS
- Sonner (notificaciones)
- jsPDF (generación de facturas)
- Context API (estado global de carrito y autenticación)

## Funcionalidades

- Catálogo de 20 productos gaming/hardware con filtro por categoría
- Carrito de compras con persistencia en localStorage
- Autenticación simulada (registro/login)
- Generación de factura en PDF con envío simulado por correo
- Diseño responsive mobile-first

## Instalación local

\`\`\`bash
cd ecommerce-dps-desaf1
npm install
npm run dev
\`\`\`

Abrir [http://localhost:3000](http://localhost:3000) en el navegador.
